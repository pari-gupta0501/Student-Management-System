About Student Management System

This is a single-file, offline-capable academic demo. It uses HTML, CSS and embedded JavaScript. Student records are saved in this browser's local storage, so the app opens directly by double-clicking this HTML file.

Important: This direct-open version does not connect to MySQL. A browser-only HTML file cannot securely connect directly to a MySQL server. Use fictional sample data only; clearing browser data can erase records.

Features: Create, view, update, delete, search, department filter, dashboard statistics and CSV export.
